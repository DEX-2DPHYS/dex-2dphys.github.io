DSW.

Pick an experiment in the tree on the left. It runs natively on this machine; this window is only its front panel.

Installing an experiment = dropping its bundle folder into the plugin library and pressing Refresh. A bundle is a folder holding dex.json, the compiled core and a ui/ page — and subfolders in the library show up as folders in the tree, so organise it like you organise files.

Write your own

The two built-in experiments are templates. The plugin ABI is seven functions in plain C — see the README.md in the dsw folder for the porting guide from an HTML prototype and the wire protocol.

Plugin folder

Your plugin library works like a VST folder: it has a standard home, and you can point it anywhere else. The folder is created if it does not exist; the choice is remembered per user, not per project.
