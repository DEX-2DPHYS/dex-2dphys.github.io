How it works

Why the wave stops

Each column of rods reflects a little. When the round trip between neighbouring columns is a whole wavelength inside the crystal, every reflection adds up in phase. At normal incidence the first gap sits near λ ≈ 2.1 a: the spacing is about half a wavelength. (The rods are thin and only a little denser than the space around them, so the wave inside is barely shorter than outside; each column reflects only a little, which is why there are many.)

What a Bloch wave looks like

Inside the lattice the field is a plane wave times a pattern with the lattice period, ψ = u(r) eik·r. The intensity view shows it bunching on the rods. At the gap edge it becomes a standing wave, and inside the gap k turns complex so the amplitude dies off exponentially.

Why direction matters

A square lattice is not the same in every direction. Tilting the wave changes which lattice planes reflect it, so the gap moves and narrows, and a few angles open narrow windows inside it. The band diagram shows this before the simulation settles.

Reading the transmission number

It is the energy measured on the detector strip divided by the same measurement in an empty second simulation, taken on rows where the incoming beam is complete. The beam has finite width, so a tilted beam that the crystal shifts sideways can read a few percent above 100%. The display is capped at 100%.
