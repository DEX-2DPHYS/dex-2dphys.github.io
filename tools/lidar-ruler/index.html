LiDAR Ruler

Point your phone, tap up to three objects, and read their distances live in the camera view — measured with the depth sensor through augmented reality.

2

3

Checking augmented-reality support…

This browser can't reach the depth sensor

The app needs WebXR augmented reality, which lets a web page use the phone's AR system (LiDAR / depth sensing) without installing anything.

Android: open this page in Chrome on an ARCore-capable phone.

iPhone / iPad: Safari doesn't yet expose LiDAR to web pages — open this page in a WebXR-enabled browser app (e.g. “WebXR Viewer”), or try it on an Android device.

Everything runs on the device — the camera image and depth data never leave your phone.
